Selected Research

Suraksha Drishti — Real-Time Surveillance & Violence Detection

AUG 2025 — PRESENT
Computer Vision · Deep Learning · Real-Time Inference
  • Developed a multi-model computer vision pipeline combining YOLOv8n person detection, ONNX MobileNetV3-LSTM temporal classification and MediaPipe Pose Landmarker.
  • Designed the system to detect seven threat classes within a real-time processing pipeline.
  • Achieved approximately 28–30 FPS with 90–110 ms end-to-end latency on commodity CPU hardware.
  • Developed a FastAPI/WebSocket backend and operator interface for live detections, evidence management, mapping and dispatch workflow.
  • Evaluated the system on a custom 320-sample CCTV-augmented test set.
Accuracy 92.81%
F1 0.93
FPS 28–30
SUS 82.5 / 100

Vehicle Number Plate Detection & Recognition

JUN — JUL 2022
Computer Vision · YOLO · Optical Character Recognition (OCR) · Real-Time Inference
  • Engineered an end-to-end Automated License Plate Recognition (ALPR/ANPR) pipeline utilizing YOLO for robust bounding-box localization of vehicles and registration plates across varying lighting, perspectives, and speeds.
  • Built a dedicated OCR processing pipeline with adaptive thresholding, morphological filtering, and perspective skew-correction to accurately isolate and parse alphanumeric characters from Indian vehicle plates.
  • Implemented syntax-checking filters and regex verification to eliminate false plate detections and automatically log recognized numbers into a timestamped incident database.
  • Optimized the pipeline for traffic-police field utility, achieving low-latency real-time video stream processing on standard CPU workstations.
Plate Detection 94.2%
OCR Accuracy ~90%
Latency ~42 ms
FPS 22–25

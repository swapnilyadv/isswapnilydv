# Deploy steps (about 10 minutes, all free)

1. GitHub: create a public repo named YOUR-GITHUB-USERNAME.github.io
   Upload everything in this folder (index.html, profile-circle.jpg, CNAME, .nojekyll, robots.txt).
2. Repo > Settings > Pages > Source: "Deploy from a branch" > main / (root). Save.
   Your site is now live at https://YOUR-GITHUB-USERNAME.github.io
3. Free domain: fork https://github.com/is-a-dev/register
   Add domains/isswapnil.json (copy is-a-dev-isswapnil.json, put your username in), open a pull request.
   Review usually takes 1-3 days. Once merged, https://isswapnil.is-a.dev works.
4. After merge: repo > Settings > Pages > tick "Enforce HTTPS".

If isswapnil is taken, use swapnilydv and change it in CNAME and index.html (canonical / og:url / og:image).
